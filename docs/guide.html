Try the browser explorer

The landing page computes PCA on 72 deterministic synthetic samples with 36 features. Drag to rotate the 3D view, switch to 2D, select samples, filter groups, inspect the table, and export the complete synthetic dataset with its coordinates. Scaling recomputes PCA; display filters do not. The 3D view is a website demonstration, not an added feature of the R app.

Both modes center the matrix. The demo uses a Jacobi eigensolver on the feature covariance matrix. Its data are generated locally and are never presented as GEO observations. The R app continues to use stats::prcomp for real data.

01 / Run locally

Install R. RStudio is optional but convenient. Package installation and GEO downloads require an internet connection.

  1. Download the app source and extract it.
  2. Open GEOPrism.Rproj in RStudio, or set your R working directory to the extracted project folder containing app.R.
  3. Run these commands in the R console:
R CONSOLE
source("install_packages.R")
shiny::runApp()

The installer includes CRAN packages and Bioconductor annotation databases. The first installation can take several minutes. For later sessions, run shiny::runApp() from the project directory.

The browser landing page is a project introduction. Dataset loading and real PCA analysis run in the R Shiny application.

02 / Explore your first dataset

  1. Load a Series. The app starts with GSE9624 in the accession field. Click Load GEO dataset. Availability depends on GEO.
  2. Choose a platform. If multiple expression sets are returned, select one. Gene mapping and PCA require a supported platform.
  3. Review samples. Inspect metadata and choose the samples and metadata columns to include. Matrix operations require at least two samples; PCA requires at least three.
  4. Inspect mapping. Review mapped and unmapped probes. Choose to average probes sharing a gene symbol or retain mapped probes separately.
  5. Assign groups. Edit the Group cells in tab 6. Group labels are optional and do not enter the PCA calculation.
  6. Explore PCA. Open tab 8. Select the feature set, PC axes, and color or shape metadata. Hover, pan, zoom, and inspect the scree plot.
  7. Export. Save matrices, metadata, coordinates, or figures for your next analysis.

Changing the accession text alone does not load new data. Always click Load GEO dataset before exporting under a different accession.

04 / What the app calculates

Expression values & annotation

Expression values come from the selected GEO ExpressionSet. GEOPrism does not add normalization, log transformation, batch correction, or missing-value imputation. Review the original study’s processing notes.

Annotation uses AnnotationDbi::mapIds with keytype = "PROBEID", column = "SYMBOL", and multiVals = "first". Unmapped probes are dropped from the gene-level matrix. When averaging is selected, mapped probes sharing a symbol are combined by their arithmetic mean.

Principal component analysis

  1. Use the selected samples and mapped expression matrix.
  2. Optionally remove samples labeled Exclude from PCA only (case-insensitive).
  3. Remove feature rows with non-finite values or zero variance.
  4. Use all remaining features or the most variable features. The default is up to 1,000, ranked by variance before scaling.
  5. Transpose the matrix to samples × features and call stats::prcomp. Centering defaults to on; unit-variance scaling defaults to off.
  6. Add sample group and metadata labels to the computed coordinates for interpretation.

If mapped probes are retained separately, PCA uses probe-level rows, even though some interface labels say “genes.” At least three samples and two variable features are required.

Interpretation

Separation in PCA is exploratory evidence, not a statistical test or proof of a biological effect. Inspect metadata and technical context before treating a distant sample as an outlier. No differential expression, model training, or enrichment analysis is implemented.

06 / A few useful answers

Why is gene mapping unavailable?

The platform may not be supported, or its annotation package may be missing. Check the platform table above and rerun the installer if needed.

Why can’t PCA run?

Check for at least three included samples, at least two finite variable features, and a supported gene mapping. Review whether too many samples are labeled Exclude. Choose two different, available PC axes.

How do I fix an SVG export dependency error?

Run install.packages("svglite") in R. The GEOPrism installer explicitly includes this export dependency.

Can I use GitHub Pages to run the app?

GitHub Pages can host this landing page and documentation. The R Shiny app needs a separate R-capable host. See Posit’s deployment guide.

Is there a tested R version or release benchmark?

This distribution does not yet include a verified runtime compatibility matrix or performance benchmark. Record your R and package versions with sessionInfo() when validating it on your machine.

Does “No labels” hide the hover tooltip?

In the current application, “No labels” removes persistent labels but sample information is still available on hover.
